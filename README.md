## 关于AI枣报

AI枣报是一个自动化AI新闻摘要系统，每天早晨09:00从50个数据源中智能筛选出最重要的AI动态。

### 核心特性
- **50个数据源**: 全面覆盖AI产业信息生态
- **10分钟自动化**: 08:50-09:00精密流程
- **11,190行代码**: 工程化的AI能力部署
- **100%自动化**: 无需人工干预

### 产品哲学
"宁可少，不要假" - 质量优于数量，建立AI信息聚合的质量标准。
