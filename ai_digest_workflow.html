📋 产品定位与价值

核心问题

  • 信息过载：每天数百条AI相关新闻，难以筛选真正重要的内容
  • 质量参差：聚合站重复、二手信息泛滥，缺乏权威来源
  • 时间成本：从业者需要花费大量时间筛选和验证信息

解决方案

精准筛选

只呈现"全球最前沿、最重大、最重要"的AI动态，过滤噪音信息

质量优先

建立严格的质量门禁，确保每条信息都有价值、可验证

时间效率

让用户在3分钟内看懂当天真正值得关注的变化

目标用户

  • AI研究人员和技术开发者
  • 科技公司产品经理和决策者
  • 投资机构和行业分析师
  • 对AI技术发展感兴趣的学习者

🔄 完整生产链路 (08:50-09:00)

每天早晨10分钟的自动化生产流程，确保09:00准时送达

08:50

数据源可用性检查

  • 确认当天哪些核心源可读
  • 生成当日可用数据源底座
  • 执行代理自愈和健康检查
  • 产出：fetch_plan（抓取计划）
# 代理自愈脚本
bash ensure_proxy_7890.sh
# 源健康检查
python check_source_availability.py
08:55

高质量候选筛选

  • 按公司分型策略抓取候选
  • 单家公司候选上限：2条
  • 已覆盖公司数：≥2家
  • 完整条目数：≥2条
  • 技术：分通道并行抓取 + 智能去重
08:55-08:58

内容增强阶段

层级 增强方式 超时时间 适用场景
L1快速 og:description + lead paragraph 3秒 高质量媒体源
L2深度 正文抽段 / JSON-LD 10秒 官方文档和技术博客
L3降级 标记quick_only=true 失败处理 禁止进入焦点区
08:58

内容完成点

  • 质量门禁验证：有效事件数≥2，焦点候选数≥2
  • 单家公司焦点上限：2条
  • 弱源处理：禁止进入S/A焦点池
  • 产出：ai_digest_stage_0858_latest.json

08:58是内容完成点，09:00不是二次编辑点

09:00

确定性发送

  • 原则：不再自由生成，只做确定性组装
  • 流程：格式校验 → 预发送校验 → send-gate发送
  • 焦点最小条数：2条（不足则输出DATA_GAP）
  • 产出：用户收到的最终AI枣报
# 发送前校验
if focus_count < 2:
    return "DATA_GAP"
# 确定性组装
assemble_final_digest(content_json)

硬规则保障

  • 时间合同：08:58内容必须完成，09:00准时发送
  • 阶段隔离：前四步只产物，不对外发送
  • 确定性发送：09:00不再通过agent自由生成
  • 质量优先：焦点不足2条时输出DATA_GAP，不降低标准

🏗️ 核心设计原则

1. 数据分层策略 (P0-P2优先级)

层级 公司/源类型 处理策略 示例
P0 公司级 8家核心AI公司 最高优先级，深度抓取 OpenAI、Google、DeepSeek、腾讯
P1 社区级 技术社区和学术平台 中等优先级，智能筛选 Hacker News、arXiv、Reddit优质社区
P2 媒体级 高质量财经科技媒体 补充优先级，质量验证 路透社、36氪、21世纪经济报道

2. 公司分型策略

官方主导型

代表：DeepSeek

主源：GitHub API + 官方文档

规则：官方源优先，搜索结果只做补充

媒体主导型

代表：OpenAI、Anthropic

主源：高质量单事件报道

规则：不强制官网直连，焦点优先使用媒体深度报道

混合型

代表：Google、腾讯

主源：官方博客 + 行业媒体

规则：能明确指向"更新/发布"的官方页可进焦点

3. 事件分级标准

等级 事件类型 焦点准入 示例
S级 重大突破性事件 ✅ 允许进入焦点 模型发布、重大合作、监管政策、重大安全事件
A级 重要产品更新 ✅ 允许进入焦点 产品能力升级、核心功能上线、关键生态动作
B级 常规信息和评论 ❌ 禁止进入焦点 评论、二手转载、弱信号跟进、目录页、指南页

💡 技术创新亮点

1. 工程门禁体系

  • 阶段化验证：每个生产阶段都有明确的质量门禁
  • 自动降级：不满足条件时自动触发DATA_GAP机制
  • 防伪保障：避免"看起来很多、实际信息稀薄"的版本

2. 多源验证与降级策略

主备切换

主源失败时自动降级到备用数据源，确保服务连续性

源健康监控

实时监控数据源可用性，建立健康度评分体系

弱源处理

优先换源，不优先美化弱源，确保信息质量

3. 自动化与确定性平衡

  • 智能筛选（08:50-08:58）：利用AI进行内容筛选和增强
  • 确定性发送（09:00）：固定格式组装，避免最后一分钟风险
  • 风险隔离：将自由生成与确定性发送严格分离

🛡️ 质量控制体系

焦点准入标准（必须同时满足）

  1. 来源层级：official或tier1_media
  2. 事件分级：S或A级（B级禁止进入）
  3. 内容质量：完整的中文标题 + 中文关键点
  4. 焦点通道：focus_lane=true且quick_only=false
  5. 公司限制：单家公司焦点上限2条

内容表达规范

标题规范

# **AI枣报 X月X日 美好一天轻松开始** 😊

标题后必须空一行，保持统一格式

焦点格式

1. 中文一句话总结
时间： 日期 + 语义时段
关键点：
- 具体动作 + 具体变化

禁止项
  • 空泛套话和过程态文本
  • 英文原标题直接进入
  • 【公司名】标签
  • 分级/事实/影响/建议字段

校验与拒发规则

检查项 标准 处理
标题格式 必须符合固定格式 ❌ 拒发
焦点数量 ≥2条高质量焦点 不足则输出DATA_GAP
过程态文本 禁止出现任何过程态 ❌ 拒发
编辑落款 必须包含编辑信息 ❌ 拒发
